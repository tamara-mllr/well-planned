# WellPlanned

A Notion-style planner for lab work: plan experiments per week, keep track of cells in culture, protocols and reagent stocks, and log each experiment with its deviations.

**Your data stays in your browser.** Nothing you type is uploaded to GitHub. Use "Export backup" in the sidebar now and then to save a backup file, and "Import backup" to load it on another computer.

The whole app is one file, `index.html`.
